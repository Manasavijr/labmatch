      How it works

      From raw grants to a ranked list.

      Three public sources, one pipeline. Every number is a real row count.

      How a lab is scored

      per query

      1. BM25 keyword search and SPECTER2 embeddings each pull the closest labs, merged by reciprocal rank fusion into 100 candidates.
      2. A LightGBM LambdaRank model re-orders them using the retrieval scores plus funding, recency and lab-size features.
      3. Its score is calibrated on held-out papers, so a higher match means more likely relevant.

      The example searches on Match come from the trained model. Text you type yourself is scored in your browser with a lighter keyword method, because this page can't run the model.
